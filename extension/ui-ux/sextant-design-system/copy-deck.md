# Copy deck

Every user-facing string in E1. `{name}` is a context name exactly as kubeconfig spells it; `{n}` a number. Strings marked † appear only for critical contexts.

## Credential Audit

| Where | String |
|---|---|
| Message | `Values are never shown.` |
| Groups | Expired · Long-lived credentials · Expiring within 30 days · Short-lived or brokered; empty group description `none` |
| Row description | `{auth} · {expiry}` e.g. `client certificate · expired 2026-03-02`, `static token · no expiry` |
| Remediation hints | Static token: replace with an exec plugin (oc login --web) · Basic auth: switch to a token issued by an identity provider · Certificate expired: run minikube update-context or re-create the cluster · Certificate valid 10 years: issue a shorter-lived certificate · Local cluster certificate: acceptable for kind; rotate yearly · Exec plugin: no action needed |
| Copy report done (status bar message) | `Audit report copied (no secret values included)` |

## Audit report (Markdown)

```markdown
# Sextant credential audit

Generated {date} from {n} contexts in {files} kubeconfig files.

**Expired {a} · Long-lived {b} · Expiring within 30 days {c} · Short-lived or brokered {d}**

| Context | Platform | Authentication | Expires | Risk | Suggestion |
|---|---|---|---|---|---|
| `minikube` | minikube | client certificate | 2026-03-02 (expired) | Expired | Re-create the cluster or run minikube update-context |

> This report lists authentication methods and expiry dates only. No tokens, keys, passwords or certificate contents are included.
```
